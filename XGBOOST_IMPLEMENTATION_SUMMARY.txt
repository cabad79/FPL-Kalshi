MODEL SPECIFICATIONS
================================================================================

Model Type:         Multi-class XGBoost Classifier
Classes:            Home Win (0), Draw (1), Away Win (2)
Input Features:     14 engineered features
Training Method:    Synthetic Elo-based EPL match generation
Hyperparameters:    n_estimators=250, max_depth=7, learning_rate=0.08

Input Feature Set:
  1. home_elo              - Home team Elo rating
  2. away_elo              - Away team Elo rating
  3. home_form             - Home team recent form (0.3-1.5)
  4. away_form             - Away team recent form
  5. home_gf               - Home team goals for per match
  6. home_ga               - Home team goals against per match
  7. away_gf               - Away team goals for per match
  8. away_ga               - Away team goals against per match
  9. elo_diff              - Elo rating differential
  10. form_diff            - Form difference
  11. strength_diff        - Goal differential strength
  12. home_xg_index        - Home expected goals index
  13. away_xg_index        - Away expected goals index
  14. home_advantage       - Home advantage constant (1.145)

Output Format:
  {
    'home_win': float,     # P(Home Win) [0.0-1.0]
    'draw': float,         # P(Draw) [0.0-1.0]
    'away_win': float,     # P(Away Win) [0.0-1.0]
    'confidence': float    # Max probability [0.0-1.0]
  }

Performance Metrics:
  - Overall Test Accuracy: 51.50%
  - Home Win Accuracy: 75.99%
  - Draw Accuracy: 2.70%
  - Away Win Accuracy: 28.93%
  - Baseline (random): 33.33%
  - Improvement over baseline: +18.2pp

Note: Model is slightly biased toward Home Wins (53% of training data),
which is realistic for EPL. Draws are inherently difficult to predict (11.5% of matches).
