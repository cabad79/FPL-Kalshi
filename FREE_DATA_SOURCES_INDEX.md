## Risks & Mitigations

### Risk 1: API Goes Down
**Mitigation:** Have 2-3 backup sources for critical data
- Primary: Football-Data.org
- Backup: API-Football free tier
- Cache layer: Store last 24h locally

### Risk 2: Rate Limits Hit
**Mitigation:** Unlikely with free tiers, but prepare
- Stagger requests (once per hour, not realtime)
- Cache responses
- Upgrade API tier ($49 unlocks 100k req/day)

### Risk 3: Web Scraping Blocked
**Mitigation:** Use official APIs first, scraping second
- APIs are more reliable anyway
- Scraping is fallback only
- Respectful rate limits (1 req/5 sec) prevent blocks

### Risk 4: Competitors With Paid Data
**Mitigation:** Your actual advantage isn't data—it's models
- Better predictions from same data
- Faster response time
- Niche expertise (FPL, Kalshi)
- Community trust (no corporate veneer)
